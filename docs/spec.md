# 仕様書

## 概要
- 群れの鳥とリズムを合わせる、オリジナルのブラウザ向けリズムゲーム。
- 「リズム天国」のミニゲーム群に着想を得た**非公式ファンメイド作品**であり、
  キャラクター・音楽・効果音・コードはすべて本プロジェクトのオリジナルです。
  原作の素材（画像・音声・楽曲）は一切使用していません。
- 静的サイトとして GitHub Pages で公開し、ブラウザだけで遊べることをゴールとします。

## ゲームルール
| 項目 | 仕様 |
|---|---|
| 入力 | クリック / スペースキー / タップ（1ボタンのみ） |
| 楽曲長 | 120 BPM、132拍 = 66秒（イントロ4拍含む） |
| 判定回数 | 50回 |
| スコア | 100点満点 |
| ピッタリ（Perfect） | 目標時刻 ±90ms → **2点** |
| 普通（Good） | 目標時刻 ±180ms → **1点** |
| 失敗（Miss） | 窓の外、または押しそびれ → **0点** |
| 余分な入力 | 得点は変わらないが、失敗モーションと注意表示が出る |
| データ保存 | なし（メモリ上のみ。ページを更新すると消える） |

計算式: 50判定 × 最大2点 = 100点。このため楽曲は「約1分」から
66秒に少しだけ伸ばしています（仕様6の許容範囲内）。

## 進行（譜面）
- 16小節（各8拍）。譜面定義は `src/logic.js` の `BAR_PATTERNS`。
- 基本は足踏み「ステップ」。一部の小節（3, 7, 11小節目と最終音）は
  「ジャンプ」（しゃがんでから羽ばたいて跳ぶ）。
- ジャンプ区間の1小節前には鳥の鳴き声キュー
  「ピーピャコ　ピャッコ　ビャー！　ビャー！！」が鳴り、画面にも表示されます。
  前半の鳴き声が合図、ジャンプ自体は譜面の拍で入力します。
- 開始時：鳥の群れが飛んでくる（フライイン）→ 着地して楽曲開始。
- 終了時：群れが飛び去る（フライアウト）→ 結果画面。

## キャラクター / モーション
- デフォルメ鳥（インラインSVG）を7羽配置し、中央のピンクの鳥（赤いスカーフ）がプレイヤー。
- モーション：
  - ステップ（毎拍、左右に小さく傾いて足踏み）
  - 成功ステップ（小さく跳ねる）
  - ジャンプ（しゃがみ → 羽ばたきながら跳ぶ）
  - 失敗（うなだれて傾き、目が×になる）
  - 飛行（羽ばたきながら上下動。イントロ/アウトロ）
- 仲間の鳥は常に譜面どおり正確に動く「お手本」です。

## 音楽 / SE（すべて Web Audio API でリアルタイム生成、音声ファイルなし）
- BGM：オリジナルのコード進行（Am–F–C–G）とペンタトニック旋律、
  キック / スネア / ハット / ベース / パッドをシンセサイズして約66秒演奏。
- SE：足音（ノイズ＋サイン波）、羽ばたき（ノイズの帯域スイープ）、
  鳴き声キューと「ビャー！」（フォルマント風のピッチスイープによる合成音声）。
- ブラウザの自動再生制限のため、AudioContext はスタートボタン押下時に生成します。

## 画面構成
- 上画面：背景は単色（空色）＋地面。群れとキュー表示、開始/結果パネル。
- 下画面（判定画面）：ニンテンドーDS風の2画面イメージで、
  - 直近の判定（ピッタリ！ / 普通 / 失敗…）
  - 早い・遅いのミリ秒表示
  - タイミングゲージ（中心がジャスト、帯が Good / Perfect の窓、印が押した位置）
  - 判定履歴ドット（最大50個）と楽曲進行プログレスバー
  を表示します。

## 結果共有
- 結果画面のボタンから X（Twitter）の投稿画面を開きます
  （`https://twitter.com/intent/tweet` にスコア入りのテキストを
  `encodeURIComponent` して渡すだけ。自動投稿はしません）。

## 対応環境
- モダンブラウザ（PC / スマホ）。タップは `pointerdown` で受け付け、
  レスポンシブ表示と `prefers-reduced-motion` に対応します。

# とりのたいぐん（tori-no-taigun-muse）

群れとリズムを合わせるオリジナルのブラウザ鳥リズムゲーム。
「鳥の大群」のような遊びに着想を得た**非公式ファンメイド作品**で、
キャラクター・音楽・効果音・コードはすべてオリジナルです。

## あそぶ
- GitHub Pages: https://astail.github.io/tori-no-taigun-muse/
- 操作：**クリック / スペースキー / タップ**（スマホ対応）
- 鳴き声「ピーピャコ　ピャッコ」のあとは「ビャー！　ビャー！！」でジャンプ。
- 判定は50回、**100点満点**（ピッタリ2点 / 普通1点 / 失敗0点）。
- 下の画面にタイミング判定（早い・遅い、ms表示）が出ます。
- 結果は X（Twitter）にポストできます。
- データは保存されません（更新すると消えます）。

## 開発


## ライセンスと注意
- 本リポジトリのコードは学習・個人利用を想定しています。
- 任天堂および「リズム天国」とは関係のない非公式ファンメイド作品です。
  原作の画像・音声・楽曲は使用していません。
